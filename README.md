# Fake News Detection with Natural Language Processing (NLP)

## Project Overview

This project focuses on the development of a Machine Learning model to detect fake news using Natural Language Processing (NLP) techniques.

The goal is to classify news articles as either real or fake based on their textual content. The project simulates a real-world scenario in which a model could support a Chrome plug-in designed to help users identify unreliable news online.

## Project Brief

The project brief required the development of a Machine Learning model for fake news detection using NLP techniques.

The model is designed to analyze real and fake news datasets, identify textual patterns, train classification algorithms, evaluate their performance, optimize the results, and prepare the model for possible integration into a Chrome plug-in.

## Dataset

The dataset was provided for educational purposes and contains two CSV files:

- True news articles
- Fake news articles

The datasets include information such as article titles, full text, subject categories, and publication dates.

Dataset source: https://proai-datasets.s3.eu-west-3.amazonaws.com/fake_news.zip

## Main Questions Explored

The project explores questions such as:

- Are fake news articles more frequent in specific categories?
- Are some topics more exposed to fake news?
- Do fake news titles show recurring textual patterns?
- Which textual features are most useful for distinguishing between real and fake news?

## Project Workflow

The project is structured into the following phases:

1. Data loading and initial exploration
2. Exploratory Data Analysis
3. Text cleaning and preprocessing
4. Feature extraction using NLP techniques
5. Model training
6. Model evaluation
7. Model validation and optimization
8. Model export preparation

## Techniques Used

- Natural Language Processing (NLP)
- Text preprocessing
- Text classification
- TF-IDF vectorization
- Logistic Regression
- Linear Support Vector Machine
- Cross-validation
- Model optimization
- Confusion matrix analysis
- Evaluation metrics: accuracy, precision, recall, and F1-score

## Model Evaluation

The models were evaluated using standard classification metrics, including:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion matrix

These metrics were used to assess the ability of the model to correctly distinguish between true and fake news articles.

## Goal of the Project

The main goal of the project is to build a reliable text classification model capable of identifying fake news based on textual patterns.

The project also demonstrates a complete Machine Learning workflow, from data exploration and preprocessing to model training, evaluation, optimization, and export preparation.
