# Fake News Detection with NLP

## Project Overview

This project focuses on the development of a Machine Learning model to detect fake news using Natural Language Processing techniques.

The objective is to classify news articles as either real or fake based on their textual content. The project simulates a real-world scenario in which a model could support a browser plug-in designed to help users identify unreliable news online.

## Dataset

The project uses two datasets:

- True news articles
- Fake news articles

The datasets include textual information such as article titles, full text, subject categories, and publication dates.

## Project Workflow

The project is structured into the following phases:

1. Data loading and initial exploration
2. Exploratory Data Analysis
3. Text cleaning and preprocessing
4. Feature extraction using NLP techniques
5. Model training
6. Model evaluation
7. Model validation and optimization

## Techniques Used

- Natural Language Processing
- Text preprocessing
- Text classification
- TF-IDF vectorization
- Logistic Regression
- Linear Support Vector Machine
- Model evaluation with accuracy, precision, recall, and F1-score
- Confusion matrix analysis

## Goal

The goal of the project is to build a reliable text classification model capable of distinguishing between real and fake news articles.
